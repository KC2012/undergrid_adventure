# 0.2 — The Hollow Signal

- Created a new standalone adventure runtime; preserved both uploaded games as unmodified references.
- Replaced separate-screen RPG shootouts with AP squad encounters in the exploration environment.
- Added six authored districts with overlapping floors, ladders, regional art, a two-axis camera and a small sector survey.
- Added the Last Light settlement, Mara's multi-stage signal quest, a gear-gated archive route, final boss encounter and playable chapter ending.
- Added two recruitable, directly controlled companions and graph-based following outside combat.
- Added four firearms, shared ammunition, magazines/reloading, armor, medkits, grenades, supply trading and XP levels.
- Added steel LOS, directional low cover, destructible crates, high ground, suppression, overwatch, barrel chains and shotgun knockback.
- Added lore terminals, optional pump repair, steam shutoff, hidden armories and discovered-terminal rail transit.
- Added autosave, manual save, validated JSON backups, pause/system menus, atlas, journal and field guide.
- Added responsive keyboard/pointer and touch controls, an offline build pipeline and Chromium integration coverage.
- Fixed click-route encounter bypass, modal retreat, ladder path endpoints for enemies, and equipment ammo conservation during implementation.
